# SafeSite test page

This page is safe to use. It's a pretend sign-in form for trying SafeSite: **nothing you type here is sent anywhere**, and the button does nothing.

Start typing in the password box. Because this site isn't on your list of safe sites, SafeSite should warn you, and its page icon should show ✗.

<form onsubmit="return false" autocomplete="off">
  <p><label>Email<br><input type="email" name="email" placeholder="you@example.com"></label></p>
  <p><label>Password<br><input type="password" name="password" placeholder="Type anything"></label></p>
  <p><button type="submit">Sign in</button></p>
</form>

Afterwards you can choose **Not now**, or open SafeSite and turn checks off for this site. If you tap **Trust this site**, SafeSite won't warn you on this site again until you mark it unsafe.
